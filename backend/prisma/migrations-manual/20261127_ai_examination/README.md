# AI Examination module – database migration

Additive only: creates 10 new tables (`AiExam*`) with foreign keys to existing
`School`, `AcademicYear`, `Class`, `Section`, `Subject` and `Student`.
No existing table or column is changed or removed.

| File | Purpose |
|---|---|
| `up.sql` | Creates the tables, indexes and foreign keys (generated by `prisma migrate diff`). |
| `down.sql` | Rollback: drops only the `AiExam*` tables. **Deletes all AI Examination data.** |

## Apply

The project uses `prisma db push`, which applies exactly `up.sql`:

```bash
cd backend
npx prisma db push
# Supabase: re-apply the Data API lockdown so the new tables get RLS
npx prisma db execute --file prisma/supabase-lockdown.sql --schema prisma/schema.prisma
```

Or run `up.sql` directly with `psql`, then the lockdown script.

## Roll back

1. Back up the data if needed (`pg_dump -t '"AiExam*"' ...`).
2. Run `down.sql` (`npx prisma db execute --file prisma/migrations-manual/20261127_ai_examination/down.sql --schema prisma/schema.prisma`).
3. Remove the `AiExam*` models and their back-relation lines from `schema.prisma`,
   remove `AiExamModule` from `src/app.module.ts`, then `npx prisma generate`.
